# Frosted Jelly patterns

Patterns in this catalog define Frosted Jelly compositions. Arc Music demonstrates them in a phone-oriented app. Apply the patterns responsively using the [responsive layout guidance](../Responsive/RESPONSIVE.md), and preserve accessible interaction and readable contrast using the [accessibility guidance](../Accessibility/ACCESSIBILITY.md).

Patterns compose the foundations and components into screen-level experiences. They are useful references for layout, hierarchy and transitions; keep app-specific data and behavior separate when adapting them.

- [Layouts and scrims](LAYOUTS_AND_SCRIMS.md) — Home feature hero, immersive artwork headers, bottom chrome, stats composition and named scrim recipes.
- [Now Playing](NOW_PLAYING.md) — artwork atmosphere, artwork masks, mode transitions, lyrics and the wave seekbar.
- [Additional patterns](ADDITIONAL_PATTERNS.md) — search, library, collection, onboarding, updater, sharing and secondary card patterns.

Each pattern points to Arc Music screens and source files as implementation examples. Start with the [component catalog](../Components/COMPONENTS.md) for the reusable building blocks, or the [token guide](../Tokens/TOKENS.md) for the system values.
