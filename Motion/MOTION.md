# Frosted Jelly motion catalog

Each motion name and recipe belongs to Frosted Jelly. Arc Music demonstrates the choreography in a working app. Apply the documented trigger, timing, relative movement and feel consistently; document product-specific variations. Generic animation APIs are implementation details.

## Motion guardrails for future apps

- Keep pressed-state movement small; use one shared default and document deliberate component overrides.
- Keep the scroll reveal based on accumulated direction so fling jitter does not strobe the controls.
- Use content-aware fades and scrims to preserve contrast as artwork changes.
- Respect reduced-motion settings: retain state changes and legibility while reducing bounce, parallax and repeated ambient movement.
- Distinguish continuous ambient loops from event-driven transitions; stop or reduce loops when their surface is not visible.
